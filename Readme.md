# Mobile Web Interface
This is a mobile web interface for the ADU-11e.

## Git and GitHub layout
The Git repository root is `mobile/`.

GitHub-managed files such as workflows and issue templates live in `.github/` under this directory.
Editor-local settings such as `.vscode/` are ignored.

## Quarto content
Quarto source files in `quarto/` are tracked.
Rendered documentation in `doc/` is tracked.
Local Quarto working artifacts in `quarto/.quarto/` and notebook cache files such as `*.quarto_ipynb` are ignored.
